# Publish a new text entry
#
# 1. Pull the latest main from fivsevn/fivsevn-flux before editing.
# 2. Set status: published for the website, or status: draft to save a draft.
# 3. Leave title: "" for a time-based heading, or enter a custom title.
# 4. Replace the body AFTER the closing --- with the new Markdown text.
# 5. Commit and push to this repository's main; wait for Publish flux to succeed.
# 6. Check the timeline and open the entry title to inspect its individual page.
#
# > Title: The default heading uses the source commit time in Asia/Shanghai.
# > Clear a custom title before the next entry to return to a time-based heading.
#
# > Date: The lower publication timestamp is stored separately from the title.
# > Both use Beijing time; editing a saved title does not change its date or URL.
#
# > Drafts: Draft packages stay off the website, but GitHub files remain public.
# > Publish a saved draft by setting status: published in its saved index.md.
#
# > Existing entries: Edit flux/YYYY/MM/{id}/index.md to revise an old post.
# > A new trigger commit with a nonempty body creates a new entry, even if only
# > these instruction comments changed. An empty body creates no package.
#
# > Formatting: Keep these comments inside the frontmatter. Frontmatter and its
# > comments are not displayed on the website. Do not paste instructions into
# > the body. Markdown links use [link text](https://example.com/).
#
# > Images: Use trigger_imgs/ for new image uploads; keep original phone names.
# > Full English instructions: README.md and trigger_imgs/README.md.
